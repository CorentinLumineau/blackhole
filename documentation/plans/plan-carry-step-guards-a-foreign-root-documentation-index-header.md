# Plan - Issue #1388

## Objective
`carryManifest` regenerates the whole root `documentation/INDEX.md` after any `new_file` carry into `documentation/` (not `decisions/`). `renderRootIndexFile` keeps only the first two lines and replaces everything else with blackhole's lowercase 5-column header and bare-path rows, so a consumer's own header, link cells and hand-written summaries are destroyed. Fix: regenerate only when the file is absent, has no table (title/blank lines only), or its table header is exactly blackhole's. Otherwise skip the regeneration, leave the consumer file byte-identical, and record a skipped entry whose reason names V-INT-01 (WARN). Pareto: Gain 10 x (11 - Effort 3) = 80 (>= 30).

Root cause (V-FIX-01): `carryManifest` sets `regenerateRootIndex` (`scripts/lib/carry-staged-artifacts.ts:346-348`) and writes `renderRootIndexFile(existing, ...)` (lines 387-396) without ever reading the existing header; `renderRootIndexFile` (`scripts/lib/doc-index-generate.ts:76-79`) treats any existing file as "title block + replaceable table".

Decision record: easy path = skip on foreign header (chosen); hard path = upsert only the new rows in the foreign file's own column order and path style. Skip is chosen because the foreign column set (e.g. invest's link-style `[x](x)` cells, tiered per-folder indexes) is not derivable from blackhole's `RootIndexRow`, and a wrong guess rewrites the consumer file again. Cost: a new doc is not indexed by the carry in a foreign-header consumer; reported as a finding. Confidence: Medium.

## Codebase Conventions
- Reuse `findTableBlock` (`check-common.ts:224`, exported) for table location; the header row is `lines[separatorIdx - 1]`. #1390's helpers (`isAdrIndexHeader`, ADR rendering) detect an `ADR` first column and do not fit a root `path` header, so no second ADR detector is added and none is reused (V-INT-02 checked).
- Header comparison: split on `|`, trim, drop the empty edge cells, compare to the exact cells `path, summary, type, status, review_trigger` (case-sensitive; the lowercase header is blackhole's, and invest's `Path | Summary | ...` is foreign by design). Define the expected cells from `INDEX_TABLE_HEADER` (first line) so there is one source of truth.
- No-table file: regenerable only if every line is blank or starts with `#` (nothing but a title block to preserve); any other prose is treated as foreign.
- Skip reasons reuse the existing `skipped.push({ index: -1, reason })` shape used at line 394; the CLI prints it on stderr and still exits 0 when other entries carried.
- Comment discipline: one rationale at `isRegenerableRootIndex`; none restated at the call site; no issue numbers in source comments (tests may name the issue).
