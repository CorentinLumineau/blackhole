is the sole future writer; a self-audit or reviewer finding a stale row files an issue, it does
not edit this file directly.

slate (9 corrections, 16 new rows, PM-086..101) against **current** repo state, not against the

because the underlying facts moved again after the issue was filed: PM-086 (hooks layer) is

(model-tier economy routing) is `adapted`, not the `gap` the issue described, because
`model-routing.md` already ships a full task-tier matrix and 5-harness slug ladder — only a
narrower residual (planner pre-discovery sub-call, reviewer `size:xs` quick-scan) is missing.

correct, the source doc's own label/count mismatch.
