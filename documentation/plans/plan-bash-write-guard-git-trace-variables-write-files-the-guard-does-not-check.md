# Plan - Issue #1246, round 10: the guard contract for `GIT_TRACE*` writes

PR #1257 has had 9 review rounds. Since round 7, almost every new BLOCK came from parsing that a
fix round itself added: the `env` option model, the `-S` splitter, `ALLEXPORT_RE`, the brace
check. The review briefs asked reviewers to "hunt for remaining fail-open paths" with no written
boundary, so the loop could not end. This plan writes the boundary first. The code change
**deletes** the parsing that kept breaking, and refuses (WARN) wherever the old code tried to
model shell behaviour.

Owner rulings: `documentation/reference/product-principles.md` (`rulings_revision: 7`) has no
ruling on hook-guard scope (R-001 docs floor, merge mode, actionman, stacking, dashboard, R-003
gate summaries). `ruling_conflicts: []`. `autonomy.mode: full`, so the orchestrator approves
this contract.

## Objective

Make the trace scan in `templates/hooks/pretooluse/utils/bash-write-target-guard.js` follow
the three-tier contract below exactly. Delete every code path the contract does not need, and
rewrite the review acceptance rule so that round 10 can converge. Main does not scan `GIT_TRACE`
at all, so every verdict below is at least as strict as main.

## Threat Model

| STRIDE | Threat | Severity | Status |
|---|---|---|---|
| Spoofing | A worktree agent spells a trace name so the guard does not recognize it (assembled name). Control: T2-3/T2-4 warn on every opaque slot word, keyed on shape, not on name | High | Mitigated |
| Tampering | Git appends a trace into the main clone or another worktree through a visible `GIT_TRACE*` assignment. Control: Tier 1 blocks, Tier 2 warns and is ingested by Triage | High | Mitigated |
| Tampering (residual) | The same write through a named residual R1-R14 (`eval`, substitution bodies, unknown wrappers, `bash -c`) | Medium | Accepted Risk |
| Repudiation | A trace write happens with no record. Control: every visible non-Tier-1 construct writes a WARN hook event | Medium | Mitigated |
| Information Disclosure | A `GIT_TRACE_CURL` file captures auth headers outside the worktree through a residual R1-R14 | Medium | Accepted Risk |
| Denial of Service | Over-warning floods Triage with hook events. Control: the WARN-volume check, plus the continuation, array and redirect exclusions | Low | Mitigated |
| Elevation of Privilege | A worktree agent writes campaign state outside its assigned root through a visible trace assignment. Control: Tier 1 and Tier 2 | High | Mitigated |
| Elevation of Privilege (residual) | The same through R5 (#1283) or R6 (#1318) | Medium | Accepted Risk |

## Code to delete or replace (exact)

1. `bash-write-target-guard.js`: delete `addSplitString` (`:987-991`) and both of its call
   sites (`:999`, `:1023`). Delete the `split` field from `envValueOption`. Remove `S` from
   `ENV_OPTION_RE`'s value letters (`[uCSa]` → `[uCa]`) and `split-string` from its long-name
   group, so every `-S` spelling is an unknown option (T2-1/T2-2).
2. `bash-write-target-guard.js`: delete `ALLEXPORT_RE` (`:952`) and its raw-text check
   (`:1471-1472`). Replace them with the token-level `set`/`shopt` rule (T2-8), evaluated per
   clause, plus the M predicate on the whole command.
3. `bash-write-target-guard.js`: delete the `bareName` brace strip (`:1008-1014`) and the
   `decodeQuotedWord`/`addTrace(assignmentSlot ? decoded : token)` flow (`:997`, `:1036-1039`).
   Replace `findGitTraceTargets` with one function that classifies each word as *exact* or
   *opaque* and applies Tier 1 and T2-3..7. It must stay under 60 lines.
4. `bash-write-target-guard.js`: compute command positions from the clause's command-word index
   (pass `k` from `skipCompoundWords` into the trace scan), and let a declarer or `env` open a
   slot run only at such a position. This replaces
   `declaring ||= DECLARERS.has(commandName(token))`, which fires on any token, and it makes rows
   73-80 hold, `case` and function bodies included.
5. `shell-lexer.js`: delete `decodeQuotedWord` and its export. **Keep `decodeAnsiC`**:
   `commandName` uses it, and removing it would turn the `$'tee\x00z'`, `$'cp\x00z'` and
   `$'export\x00z'` BLOCK rows into allows. Drop `decodeQuotedWord` from the guard's `require`.
